## Run Locally

To run this portfolio on your local machine:

1. Clone the repository:

   ```bash
   git clone https://github.com/sindhurani04/sindhu-portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd sindhu-portfolio
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## Deployment

This portfolio is deployed using Vercel. Updates pushed to the connected GitHub repository can trigger new deployments according to the project's deployment settings.
